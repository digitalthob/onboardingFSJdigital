# Makermobil Team-Organisation – Interaktiver Selbstlernkurs

Interaktiver HTML-Selbstlernkurs zur Team-Organisation des Makermobil-Teams (LMZ / DIGITALWERKSTATT Karlsruhe).

## Inhalte (7 Lektionen)

1. 📅 Kalenderpflege makermobil@
2. 🗂️ Planner 2026
3. 💬 Teams Team "Projektbüro"
4. 🚐 Teams Team "Makermobil" (Standort-Kanäle)
5. ⚡ Chat vs. Kanal
6. 📓 OneNote & Passwörter
7. 🕐 Feste Treffzeiten

## Features

- 7 Lektionen × 2 Slides (Theorie + Praxis) + Abschluss
- Quiz-Interaktionen (Single-Choice)
- Drag & Drop (Nachrichten zuordnen)
- Checklisten für Praxisaufgaben
- Fortschrittsanzeige & Lektions-Navigation
- Abschluss-Checklisten für neue und bestehende Teammitglieder
- Design in makermobil/LMZ Markenfarben

## Hosting

Die Seite wird über GitHub Pages gehostet. Die `index.html` ist eine eigenständige statische HTML-Datei ohne externe Abhängigkeiten.
